# studio/ — the methods (the HOW)

This folder holds *how the owner does things well* — the writing rules, the quality bar, and a
playbook per craft. It starts nearly empty on purpose: methods are **earned by doing**, then
written down so the next time is easier and any agent can follow them.

## What's in here

| File / folder | What it holds |
|---|---|
| [`POSITIONING.md`](POSITIONING.md) | What the business says to the world — who it's for, what it promises, in what tone. Drafted after the first grill; refined forever. Anything outward-facing must match it. |
| [`voice/WRITING-CONSTANTS.md`](voice/WRITING-CONSTANTS.md) | **The writing rules** — how everything is written, everywhere. Read before writing anything the outside world sees. |
| [`production/QUALITY-GATE.md`](production/QUALITY-GATE.md) | **The quality bar** — the checklist every finished piece passes before it ships. Read it twice: before starting (as the brief) and at the end (as the audit). |
| [`playbooks/`](playbooks/) | One folder per craft. **[`video-editing/`](playbooks/video-editing/README.md)** is the starter — editing basics + green screen on a Mac. |

## The rule for growing this folder

When the owner does something for the second time, ask: *"want me to write down how we do
this, so next time is faster?"* One page, plain words, concrete steps. That's how a one-person
business builds a repeatable machine. Propose the doc first; create it on a yes.
