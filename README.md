# Business OS — a starter kit for running a one-person business with an AI

One folder that works as a complete operating system for a new business: the owner's thinking
(`brain/`), their methods (`studio/`), and a living board of what's happening (`now/`) — all
plain markdown, run by an AI assistant (built for [Claude Code](https://claude.com/claude-code)),
with a weekly rhythm kept alive by two small scheduled scripts. Made for a **non-technical
owner**: the AI does the technical work and guides them through everything, starting with a
fully guided setup.

**Are you the new owner?** You don't need to read anything here. Open this folder in Claude
Code and type **"set me up"** — or start from [`START-HERE.md`](START-HERE.md).

**Are you an AI agent?** Read [`CLAUDE.md`](CLAUDE.md) first — it routes everything, starting
with the first-run check.

What's inside, briefly: a guided onboarding skill (personalization → GitHub backup → business
capture) · the [`grill-me`](.claude/skills/grill-me/SKILL.md) interview skill + a
[fill-up plan](brain/grill-plan.md) that captures the owner's business in their own words ·
an issue board with a prime directive (close what you open) · deterministic week-roll +
board-doctor automation ([`OPERATIONS.md`](OPERATIONS.md)) · starter playbooks for
[video editing](studio/playbooks/video-editing/README.md), green screen, and AI-built video
(HyperFrames).

⚠️ If you cloned this: it's a **public template**. Your own business data belongs in your own
**private** repo — the onboarding re-points the remote for you before the first push.
