# The grill plan — filling the system up, one interview at a time

> **The fill-up tracker.** Every document below starts as an empty template; each gets filled
> by a [`grill-me`](../.claude/skills/grill-me/SKILL.md) interview (~15–25 min each), in the
> owner's words. **Agents: until every row is ✅, offer the next-best session at a natural
> moment in every conversation** — gently, once per session, never blocking real work. Update
> this file after every grill.
>
> Order matters loosely: do them top to bottom unless the owner's energy points elsewhere.
> One session can feed several documents; several sessions can deepen one.

|---|---|---|---|

**Statuses:** ⬜ not started · 🟡 in progress (capture exists, doc partly filled) · ✅ filled
(doc updated + owner confirmed it reads true).

## Done means

Every row ✅, and the owner has read `brain/operating-system.md` + `studio/POSITIONING.md` and
said *"yes, that's my business."* From then on, re-grills happen whenever something changes
("grill me again about pricing") — the plan can grow new rows anytime the system gains a new
empty document.
