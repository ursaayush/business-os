# insights/ — catch ideas the moment they happen

Ideas evaporate. When the owner says **"save this insight"** (or clearly just had one), append
it to today's file — `<YYYY-MM-DD>.md` in this folder — **in their words**, one dated bullet
per insight. Create the file if it doesn't exist:

```markdown
# Insights — <YYYY-MM-DD>

- <HH:MM> — <the insight, in the owner's words>
```

Rules: their words, not a paraphrase · never overwrite, only append · no judging or filtering —
capture first, evaluate later. These files are fuel: for content, for decisions, for the next
grill session.
